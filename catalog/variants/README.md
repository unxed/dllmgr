# Variants

This directory holds whole-DLL alternatives that are not tied to one bug: a
module taken from another Wine release, or a third-party library such as cc580.
One file is `<dll>-<provider>-<version>.md` (underscores of the DLL name written
as `-`), in the format described in `../README.md`. There are no entries yet.
Fixes tied to one bug go to `../fixes/`.
