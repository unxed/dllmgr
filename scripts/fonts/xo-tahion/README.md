# XO Tahion (unmodified)

Metric-compatible Tahoma analogue (Latin + Cyrillic, regular and bold) by
ООО «Новые облачные технологии» (New Cloud Technologies Ltd., МойОфис / MyOffice),
designer V. Chufarovsky, hinting ParaType. Used by `dllmgr set <app> tahoma=xo`
(#66): copied into the application's prefix (`C:\windows\Fonts`) and served for
Tahoma requests inside that application only.

- Source: https://myoffice.ru/files/fonts/MyOffice_XO_Fonts_1.1.zip

  files `XO_Tahion/XO_Tahion/TTF/XO_Tahion_Nu.ttf`, `XO_Tahion_bold.ttf`, unchanged.
